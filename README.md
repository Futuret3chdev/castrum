# Castrum

A Roman fort defense. Raise the castrum at the ford, man the engines, and hold the gate.

Place scorpios, archers, cohorts, ballistas, naphtha, and onagers on the stone pads. Sound the bucina to call each host. Raiders, Gauls, falxmen, cataphracts, bare-sarks, rams, elephants, and a king will try the road.
